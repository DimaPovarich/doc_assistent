# 📄 Ассистент по документам (`.txt` / `.docx`)

Локальное веб-приложение на **Python** и **Streamlit** для семантического поиска и ответов на вопросы **строго по содержимому загруженного документа** с указанием источника, позиции в тексте и точных цитат.

Проект работает **без генеративных LLM и сторонних API вроде Ollama**: ответ формируется из наиболее близких по смыслу фрагментов документа, а если релевантного фрагмента нет (оценка ниже порога `min_score`), система честно сообщает, что ответ в файле не найден.

---

## ✨ Возможности

* **Парсинг `.txt` и `.docx`** — извлечение текста с сохранением информации о разделе и номере строки/абзаца.
* **Чанкинг с перекрытием** — нарезка длинных фрагментов на чанки (`chunk_size`) с заданным пересечением (`overlap`), чтобы не терять контекст на стыках.
* **Семантический поиск** — построение векторных представлений с помощью `sentence-transformers` (`paraphrase-multilingual-MiniLM-L12-v2`) и расчёт косинусного сходства (`cosine_similarity`).
* **Контроль релевантности и источники** — фильтрация слабых совпадений по порогу `min_score` и вывод точных цитат с указанием места в документе.
* **Веб-интерфейс на Streamlit** — загрузка собственных `.txt` / `.docx` файлов, выбор примеров из `data/`, настройка параметров поиска и просмотр источников.

## 🚀 Как запустить проект от начала и до конца

### 1. Подготовьте окружение
Убедитесь, что установлен **Python 3.10+** (рекомендуется 3.10–3.12). Откройте терминал в корневой папке проекта `doc_assistant` и создайте виртуальное окружение:

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```
2. Установите зависимости
В активированном виртуальном окружении установите нужные библиотеки:
```powershell
pip install streamlit python-docx sentence-transformers scikit-learn
```
(Если в корне проекта есть requirements.txt, можно выполнить pip install -r requirements.txt.)

3. Подготовьте документы
Поместите файлы для анализа в папку data/ (например, sample_notes.txt или sample_lecture.docx) либо подготовьте свой документ в формате .txt (в кодировке UTF-8) или .docx.

4. Запустите веб-приложение
Убедитесь, что в терминале выбрана папка doc_assistant и активно окружение (venv), затем выполните:
```powershell
streamlit run app.py
```

После запуска в терминале появится локальный адрес (обычно http://localhost:8501), а приложение откроется в браузере.

### 5. Работа в интерфейсе

1. **Загрузите или выберите документ** в левой части экрана (`1. Документ`): загрузите свой файл `.txt` или `.docx` либо выберите готовый пример из папки `data/`.
2. **Проиндексируйте документ** кнопкой *«Проиндексировать документ»* (или задайте вопрос сразу — пайплайн выполнит индексацию автоматически при первом запросе к новому файлу).
3. **Настройте параметры поиска** на боковой панели при необходимости:
   * `chunk_size` — максимальный размер чанка в символах (по умолчанию `500`);
   * `overlap` — размер перекрытия между соседними чанками в символах (по умолчанию `80`);
   * `top_k` — число наиболее близких фрагментов для анализа (по умолчанию `3`);
   * `min_score` — порог косинусного сходства для выдачи ответа (по умолчанию `0.25`).
4. **Задайте вопрос** в блоке `2. Вопрос по документу` и нажмите *«Найти ответ»*, чтобы получить ответ, оценку сходства (`score`) и раскрывающиеся карточки с точными цитатами и координатами в файле.

## 💡 Примечания

* **Первый запуск и скачивание модели:** при первом семантическом поиске `sentence-transformers` загрузит модель `paraphrase-multilingual-MiniLM-L12-v2` с Hugging Face и сохранит её в локальный кэш (`~/.cache/huggingface/hub` или `C:\Users\<Имя>\.cache\huggingface\hub`). Повторные запуски будут проходить заметно быстрее.
* **Предупреждение о `symlinks` на Windows:** сообщение о том, что символические ссылки недоступны без режима разработчика или прав администратора, носит информационный характер и не мешает работе кэша.
* **Кодировка:** сохраняйте исходный код и текстовые файлы в **UTF-8**.
